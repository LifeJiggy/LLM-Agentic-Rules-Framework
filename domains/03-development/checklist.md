# Development Domain - Checklist

## Overview

This checklist verifies development best practices are followed.

## Priority Guide

- P0: Required where code can cause data loss, unsafe actions, or production outages.
- P1: Required for maintainable production delivery unless explicitly accepted.
- P2: Recommended for consistency and long-term quality.
- P3: Useful refinement for developer experience.

## Pre-Development Checklist

- [ ] Requirements understood
- [ ] Architecture designed
- [ ] Dependencies identified
- [ ] Project structure created

## Implementation Checklist

- [ ] Code follows style guide
- [ ] Functions are small and focused
- [ ] Error handling implemented
- [ ] Unit tests written
- [ ] Documentation updated

## Code Review Checklist

- [ ] No placeholder code
- [ ] No hardcoded values
- [ ] Proper naming
- [ ] DRY principles followed
- [ ] Security considerations addressed

## Post-Development Checklist

- [ ] All tests pass
- [ ] Code builds successfully
- [ ] Documentation complete
- [ ] No security issues

## Sign-Off

- [ ] Self-review complete
- [ ] Peer review complete
- [ ] Documentation reviewed
