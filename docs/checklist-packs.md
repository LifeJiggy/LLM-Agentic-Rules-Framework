# Checklist Packs

Checklist packs are curated sets of domain checklists for common project types.

## Production User-Facing Assistant

Use when an AI system responds directly to external users.

- `domains/01-core/checklist.md`
- `domains/02-security/checklist.md`
- `domains/04-data/checklist.md`
- `domains/07-testing/checklist.md`
- `domains/06-operations/checklist.md`
- `domains/09-performance/checklist.md`
- `domains/10-compliance/checklist.md`

Required evidence:

- AI system register.
- Evaluation plan and latest results.
- Security and privacy review.
- Release checklist.
- Incident runbook.

## Internal Agentic Automation

Use when an agent executes internal workflows or calls tools.

- `domains/01-core/checklist.md`
- `domains/03-development/checklist.md`

- `domains/02-security/checklist.md`
- `domains/06-operations/checklist.md`

Required evidence:

- Permission review.
- Evaluation plan.
- Rollback or disablement plan.

## Retrieval-Augmented Generation

Use when generated answers depend on retrieved documents or data.

- `domains/01-core/checklist.md`
- `domains/04-data/checklist.md`
- `domains/02-security/checklist.md`
- `domains/07-testing/checklist.md`

## Regulated Workflow

Use when output can affect rights, money, health, safety, employment, legal position, eligibility, or access.

- `domains/01-core/checklist.md`
- `domains/02-security/checklist.md`
- `domains/04-data/checklist.md`
- `domains/07-testing/checklist.md`
- `domains/06-operations/checklist.md`
- `domains/08-documentation/checklist.md`
- `domains/10-compliance/checklist.md`

Required evidence:

- Compliance evidence pack.
- Human oversight policy.
- Model and prompt change review.
- Safety evaluation pack.
- Incident runbook.
