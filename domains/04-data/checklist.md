# Data Domain - Checklist

## Overview

This checklist verifies data handling best practices.

## Priority Guide

- P0: Required for personal, sensitive, confidential, or regulated data.
- P1: Required for production data correctness and recoverability.
- P2: Recommended for governance and operational quality.
- P3: Useful refinement for analytics and documentation maturity.

## Data Management Checklist

- [ ] Data validated on input
- [ ] Sensitive data encrypted
- [ ] Proper indexes created
- [ ] Transactions used appropriately
- [ ] Backups scheduled
- [ ] Data retention policy defined

## Security Checklist

- [ ] No SQL injection vulnerabilities
- [ ] Prepared statements used
- [ ] Access controls implemented
- [ ] Audit logging enabled
