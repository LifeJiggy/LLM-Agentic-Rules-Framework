# /rules-plan

Create an implementation plan using the LLM & Agentic Rules Framework.

## Prompt

Create a plan for the requested AI, LLM, agentic, RAG, MCP, or coding-agent feature. Use the framework's domain routing and checklist packs.

Include:

- selected domains and why;
- P0/P1 controls;
- implementation steps;
- test and evaluation plan;
- release checklist;
- documentation and evidence updates;
- operational risks and rollback plan.

## Planning Constraints

- Put P0/P1 controls before implementation convenience work.
- Treat model, prompt, retrieval, and tool changes as release-impacting work.
- Add a short definition of done for the plan.
