# Framework Context

## Purpose

The LLM & Agentic Rules Framework provides standardized rules, practices, and checklists for teams building robust, secure, maintainable, and auditable AI systems.

## Version

1.1.0

## Domains

| # | Domain | Focus |
|---|--------|-------|
| 01 | Core | Architecture, context, tools, state |
| 02 | Security | Prompt injection, data protection, access control |
| 03 | Development | Code quality, maintainability, reviews |
| 04 | Data | Privacy, governance, pipelines |
| 05 | Integration | APIs, webhooks, tool contracts |
| 06 | Operations | CI/CD, observability, scaling |
| 07 | Testing | Unit, integration, E2E, regression |
| 08 | Documentation | API docs, runbooks, guides |
| 09 | Performance | Latency, throughput, caching |
| 10 | Compliance | Governance, risk controls, audit |

## Rule Priority Levels

- P0 Critical: Security, safety, compliance, data-loss risk
- P1 High: Reliability, quality, maintainability risk
- P2 Medium: Meaningful quality improvement
- P3 Low: Helpful refinement

## Domain File Structure

Each domain contains 7 files:
- fundamentals.md
- best-practices.md
- anti-patterns.md
- checklist.md
- examples.md
- troubleshooting.md
- advanced.md

## Target Audience

- AI and ML engineers
- Software developers integrating AI
- DevOps and platform engineers
- Security professionals
- Technical leads
- Compliance and governance teams
