# Documentation Domain - Fundamentals

## Overview

This document covers documentation fundamentals for LLM/agentic systems.

## Types of Documentation

1. **README** - Project overview
2. **API Docs** - Endpoint documentation
3. **Code Docs** - Inline documentation
4. **Runbooks** - Operational procedures
